# More Than Programming: Visual and interactive approach to Data Structures and Algorithms
 An app for learning datastructures and algorithms, the aim is to help beginners, and people who want to learn this subject. Back then I wish I had such a tool in my pocket that I could've used.

 It supports two language explanations, and animations with built in code running module, where the user can easily edit, write and run the code along with multiple files as well.
